# G S K Sanjay Varma — Personal Developer Portfolio

An extraordinary personal portfolio and digital identity for **G S K Sanjay Varma** — Software Engineer, Developer, and Builder. Designed with Apple-level visual refinement, Linear-level precision, and editorial typography.

---

## ✦ Highlights & Features

- **Apple & Linear Aesthetic**: Warm premium white canvas (`#FAFAF8`), deep charcoal showcase (`#111111`), refined typography, and purposeful whitespace.
- **Asymmetric Editorial Hero**: Dominant typography, availability indicator, and an interactive distributed systems architecture canvas.
- **Selected Work Showcase**: 
  - *Aether Engine*: Distributed streaming broker with an interactive telemetry & Raft cluster console.
  - *Linearis Workspace*: Keyboard-first sprint tracker with local-first optimistic mutations and interactive UI board.
  - *PulseEngine APM*: Deep dark showcase featuring real-time latency anomaly detection and terminal stream.
  - *Cognito Neural Canvas*: Semantic retrieval engine with bounding-box citation highlights.
  - *Architecture Inspector*: In-depth modal drawer for inspecting system components, pipelines, and problem/solution breakdowns.
- **Editorial About Section**: Storytelling layout with core engineering principles and quick metrics dossier.
- **01–06 Technical Competencies**: Categorized skill catalog without artificial progress bars or percentage ratings.
- **Experience & Education Timeline**: Reverse-chronological timeline covering B.Tech CSE, software engineering internships, leadership, and honors.
- **Active Technical Focus**: Documenting ongoing research into distributed consensus, CRDTs, LSM storage engines, and web performance.
- **Command Palette (`⌘K`)**: Quick keyboard navigation palette inspired by Linear and Raycast.
- **Centralized Content Management**: All content lives in a single, typed file (`src/data/portfolio.ts`) — easily updated without touching UI code.
- **100% Accessible & Responsive**: Strict focus indicators, semantic landmarks, fluid typography with `clamp()`, and mobile drawer navigation.

---

## 🛠 Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Typography**: Inter (Sans), Newsreader (Editorial Serif), JetBrains Mono (Monospace)
- **Deployment Ready**: Fully static and serverless compatible (Vercel, Netlify, Cloudflare)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```

---

## ✏️ How to Customize Your Content

All content is centralized in:
```
src/data/portfolio.ts
```

Simply update your personal details, project metrics, experience, skills, and links in this single file. The entire portfolio updates automatically.

To replace the resume with your actual PDF document:
Replace `public/resume.pdf` with your updated resume file.
